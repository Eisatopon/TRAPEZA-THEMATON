# Data (Θέματα σε JSON)

Σε αυτόν τον φάκελο περιέχονται **επίσημα θέματα εξετάσεων Μαθηματικών**
σε αρχεία **JSON**, οργανωμένα **ανά έτος**.

Τα αρχεία προορίζονται για επεξεργασία από εφαρμογές
(αναζήτηση, φιλτράρισμα, εξαγωγές, αυτοματισμούς).

## Σημείωση

Η ύπαρξη ενός έτους στη λίστα **δεν προϋποθέτει** ότι το αρχείο
έχει ήδη συμπληρωθεί.

Τα αρχεία μπορούν να προστίθενται ή να ενημερώνονται σταδιακά.
